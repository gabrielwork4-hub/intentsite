Schema Markup: o Que É, Para Que Serve e Como Implementar com JSON-LD

O schema markup descreve o conteúdo da página em um vocabulário que os buscadores entendem. Não é um atalho de ranking, mas é a forma de dizer às máquinas quem é a empresa, quem escreveu o texto e o que cada página é.

O Que É Schema Markup

Schema markup, ou dados estruturados, é um código adicionado à página que descreve o conteúdo com um vocabulário padronizado, o schema.org. Em vez de deixar o buscador deduzir, o código afirma: esta página é um artigo, escrito por esta pessoa, publicado nesta data, dentro deste site. O leitor não vê nada; o robô lê.

Schema Melhora o Ranking?

Não há evidência de que o schema, sozinho, suba a posição de uma página. O ganho é de outra natureza: a marcação torna a página elegível a resultados enriquecidos (rich results) quando o Google os oferece para aquele tipo de conteúdo, e deixa explícitas informações que de outro modo seriam inferidas, como a organização por trás do site e o autor do texto. Esse papel de tornar a página legível para máquinas também interessa à otimização para buscas com IA (GEO).

JSON-LD, Microdata e RDFa

O schema pode ser escrito em três formatos. O JSON-LD é o recomendado pelo Google: fica em um bloco script separado e não se mistura com o HTML visível, o que facilita escrever, revisar e manter. Microdata e RDFa são inseridos dentro das tags da página, e qualquer mudança de layout pode quebrá-los. Para sites novos, use JSON-LD.

Tipos de Schema que a Maioria dos Sites Usa

Organization

Nome, logo, site, redes sociais e área de atuação da empresa. É a base para o buscador reconhecer a marca como uma entidade e costuma ficar na página inicial.

Article

Para posts de blog: título, imagem, autor, data de publicação e data de modificação. Mantenha a data de modificação verdadeira, atualizada apenas quando o conteúdo mudou de fato.

BreadcrumbList

Descreve a trilha de navegação (Home, Blog, página atual). Ajuda o buscador a entender onde a página está na estrutura do site, o que reforça a lógica de topic clusters.

LocalBusiness

Para negócios com endereço físico ou área de atendimento: endereço, telefone, horário e coordenadas. Complementa o Google Meu Negócio e o trabalho de SEO local.

FAQPage

Marca perguntas e respostas que estão visíveis na página. Atenção ao estado atual: o Google retirou os rich results de HowTo em 2023 e os de FAQ em maio de 2026, e removeu a documentação do FAQ em junho de 2026. Marcar FAQPage não garante nenhum resultado enriquecido. O que continua útil é a pergunta bem respondida, visível na página para o leitor.

Product

Para e-commerce: nome, preço, disponibilidade e avaliações do produto. É o tipo com maior impacto visual nos resultados de lojas, desde que os dados da marcação coincidam com os da página. Veja o contexto em SEO para e-commerce.

Exemplo de JSON-LD

Este é um modelo mínimo de Article. Troque os valores de exemplo pelos dados reais da sua página:

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "Título do artigo",
  "image": "https://www.exemplo.com.br/imagem.webp",
  "datePublished": "2026-01-15",
  "dateModified": "2026-02-10",
  "author": {
    "@type": "Person",
    "name": "Nome do Autor"
  },
  "publisher": {
    "@type": "Organization",
    "name": "Nome da Empresa",
    "logo": {
      "@type": "ImageObject",
      "url": "https://www.exemplo.com.br/logo.png"
    }
  }
}
</script>

Como Implementar em 5 Passos

  1. Escolha o tipo certo para cada modelo de página: Article para posts, Product para produtos, LocalBusiness para a página do negócio local.
  2. Escreva o JSON-LD à mão ou com um gerador, usando só informações que aparecem na página.
  3. Cole o bloco no head ou no body da página. Em WordPress, um plugin faz isso; em HTML estático, é só colar o bloco script.
  4. Valide antes de publicar (próxima seção).
  5. Monitore no Search Console, onde erros de marcação aparecem nos relatórios de melhorias.

Como Validar a Marcação

Use duas ferramentas gratuitas. O Teste de Rich Results, do Google, mostra se a página é elegível a resultados enriquecidos e aponta erros. O Schema Markup Validator (validator.schema.org) confere se a marcação segue o vocabulário, independentemente de o Google exibir o resultado. Depois de publicar, acompanhe os relatórios do Google Search Console.

Erros Comuns

  • Marcar o que não aparece na página. A marcação deve refletir o conteúdo visível; dados que só existem no código violam as diretrizes do Google.
  • Dados divergentes. Preço, data ou autor diferentes entre a marcação e a página geram erro e perdem a confiança do buscador.
  • Marcar FAQ esperando rich result. O resultado enriquecido de FAQ não aparece mais para nenhum site.
  • Copiar um bloco pronto sem trocar nome, URL e logo de outra empresa.
  • Esquecer a manutenção. Mudou o preço, o endereço ou o autor? Atualize o JSON-LD junto com a página.

Schema e Buscas por IA

Mecanismos de busca com IA leem a página como texto, e a marcação ajuda a deixar claro quem é a fonte e o que cada trecho representa. Não existe garantia de que o schema leve a citações em respostas de IA; ele é uma camada de clareza, somada a conteúdo útil e a uma estrutura de site coerente. Para o quadro mais amplo, leia sobre IA generativa e SEO e o guia de SEO técnico.

Perguntas Frequentes sobre Schema Markup

O que é schema markup?

Schema markup, ou dados estruturados, é um código adicionado à página que descreve o conteúdo em um vocabulário padronizado (schema.org) para que buscadores entendam o que cada página é, quem a escreveu e a quem pertence.

Schema markup ajuda no SEO?

Não há evidência de que o schema, sozinho, melhore a posição da página. Ele ajuda a tornar a página elegível a resultados enriquecidos e a deixar claras as informações sobre organização, autor e conteúdo, o que beneficia a leitura da página por buscadores e sistemas de IA.

Qual formato de schema devo usar?

O JSON-LD, recomendado pelo Google. Ele fica em um bloco de script separado do HTML visível, o que facilita escrever, revisar e manter, ao contrário de Microdata e RDFa, que se misturam com as tags da página.

Como testar se o schema está correto?

Use o Teste de Rich Results do Google para verificar a elegibilidade a resultados enriquecidos e o Schema Markup Validator (validator.schema.org) para conferir o vocabulário. Depois de publicar, acompanhe os relatórios do Search Console.

Preciso de plugin para usar schema markup?

Em WordPress, plugins de SEO geram o JSON-LD automaticamente. Em sites de HTML estático, basta colar o bloco de script na página. Nos dois casos, valide o resultado e confira se os dados batem com o conteúdo visível.
